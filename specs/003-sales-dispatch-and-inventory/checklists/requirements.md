# Lista de control de calidad de la especificación

- [x] La venta contiene comprador, destino, vehículo, lotes, cantidades, precio, flete y pago.
- [x] Los efectos sobre inventario y cuentas son verificables.
- [x] Se consideran contado, crédito, comprobante y auditoría.
- [x] Se declaran los estados necesarios para operación offline.
- [x] Los vacíos de Figma se comunican a la tarea de diseño.
- [x] El alcance y la trazabilidad de comprobantes se han reconciliado en la documentación.
- [x] Las reglas de reserva y conflicto de lotes se han resuelto.
- [x] Las reglas de devolución, anulación y crédito se han resuelto.
