# Historias de Usuario

Las historias de usuario describen las principales necesidades de los actores que interactúan con la aplicación móvil de gestión comercial de los mayoristas de papa.

| ID | Historia de usuario |
|---|---|
| HU01 | Como mayorista, quiero registrar la llegada de un cargamento indicando proveedor, fecha, teléfono, vehículo, conductor y tipos de papa, para tener identificada la operación desde el inicio. |
| HU02 | Como mayorista, quiero registrar el peso de cada saco de papa y asociarlo con su variedad, para conocer el peso total y la cantidad de sacos del cargamento. |
| HU03 | Como mayorista, quiero registrar el precio acordado, el flete y los adelantos, para calcular correctamente el monto líquido que debo pagar al proveedor. |
| HU04 | Como mayorista, quiero registrar pagos al contado o en cuotas, para controlar los saldos pendientes con los proveedores. |
| HU05 | Como mayorista, quiero consultar el inventario por variedad y lote, para conocer la cantidad disponible y apoyar las decisiones de venta. |
| HU06 | Como mayorista, quiero registrar ventas y despachos indicando comprador, destino, vehículo, variedades, cantidad de sacos, precio y flete, para controlar los envíos realizados. |
| HU07 | Como mayorista, quiero registrar cobros y pagos, para mantener actualizadas las cuentas por cobrar y las cuentas por pagar. |
| HU08 | Como mayorista, quiero registrar los costos de estiba asociados a las operaciones, para conocer los gastos reales de carga y descarga. |
| HU09 | Como mayorista, quiero consultar reportes de compras, ventas, inventario, pagos, deudas y resultados, para evaluar el estado del negocio. |
| HU10 | Como mayorista, quiero consultar tendencias y patrones de precios basados en la información histórica, para disponer de información de apoyo para la toma de decisiones. |
| HU11 | Como mayorista, quiero que la aplicación funcione temporalmente sin conexión a Internet, para continuar registrando operaciones cuando la conectividad sea inestable. |
| HU12 | Como encargado, quiero registrar el peso de cada saco durante la descarga y asociarlo con su variedad, para mantener el registro del cargamento cuando el mayorista no se encuentre disponible. |
| HU13 | Como encargado, quiero registrar los datos necesarios de una compra autorizada, para mantener la continuidad de las operaciones comerciales durante la ausencia del mayorista. |
| HU14 | Como encargado, quiero registrar los datos de una venta autorizada, para mantener la continuidad de las operaciones comerciales durante la ausencia del mayorista. |
| HU15 | Como encargado, quiero registrar pesajes, compras y ventas temporalmente sin conexión a Internet, para continuar trabajando cuando exista una interrupción de conectividad. |
